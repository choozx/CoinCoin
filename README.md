# 코인 지표 알람 서비스 (feat.slack)

## 설명

----
이 서비스는 코인들의 지표들을 알려주는 서비스이다.
현재 거래소에서는 가격의 대한 실시간 알람은 있지만 지표의 대한 알람은 없다고 확인된다.
따라서 해당 서비스가 필요하다고 생각되어 만들었다.

## 명령어

----
슬랙 채널에 들어오게 되면 SlackBot이 존재한다. 명령어는 해당 봇을 맨션후 명령어를 입력하면된다.

`@CoinBot` [명령어]

1.도움말\
`/h`\
어떤 기능이 있는지 알려주는 명령어

2.새로운 코인 추가하기\
`/ss [코인 심볼]` ex) /ss BTCUSDT\
새롭게 추적하고 싶은 코인을 추적코인에 추가해준다.\
**최대 추적 가능한 코인의 갯수는 5개이다.**

3.추적 코인 제거하기\
`/sd [코인 심볼]` ex) /sd BTCUSDT\
코인 추적 리스트에서 제거한다.\
